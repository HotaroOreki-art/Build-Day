Simple Countdown Timer

This is a small web-based countdown timer that lets you enter a number of seconds and watch it count down to zero. When the time is up, the timer sends a desktop notification and plays a short beep sound. It works in any modern browser on Windows, macOS, Linux, and ChromeOS.

The interface is straightforward: type in the seconds, press Start, and the timer begins. You can pause it at any time and resume from where you left off, or reset it to clear everything and start again. Everything runs completely in the browser—no backend, no installation, and no extra setup.

This project is meant to be simple, easy to understand, and a good starting point for learning basic web concepts like timers, notifications, and playing sounds. You can host it anywhere, including GitHub Pages, and it will work as long as the page is loaded over HTTPS.

Feel free to use it, change it, or build on top of it.
